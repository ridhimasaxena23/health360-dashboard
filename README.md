# Health360: Healthcare Risk & Disease Analytics

A responsive, interactive academic dashboard demonstrating healthcare risk analysis across heart disease, diabetes, and stroke. It is built with plain HTML, CSS, and JavaScript, so no installation, database, login, or Tableau licence is required.

## Live demo

After publishing through GitHub Pages, the demo URL will be:

`https://YOUR-GITHUB-USERNAME.github.io/health360-dashboard/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username. The repository must be named `health360-dashboard` for this exact URL.

## Features

- Filters by age group and health condition
- KPI cards: patient count, high-risk rate, BMI, and activity rate
- Disease-prevalence chart by demographic segment
- Risk distribution and leading risk-factor analysis
- Personal risk explorer with instant educational recommendations
- Plain-language public-health insights
- Responsive layout that works on mobile and desktop
- Clear academic and medical-use disclaimer

## Run locally

Double-click `index.html` to open it in a browser. No command or dependency is needed.

## Publish on GitHub Pages

1. Create a new GitHub repository called **health360-dashboard** and choose **Public**.
2. Upload all files in this folder (`index.html`, `styles.css`, `script.js`, `README.md`, and `.gitignore`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait 1–3 minutes, refresh the Pages screen, and copy the generated site URL.

## Important submission notes

- The dashboard deliberately uses synthetic data. Do not describe it as real patient data.
- This is a course demonstration, not a diagnostic tool.
- Do not upload passwords, API keys, personal health data, or `node_modules`.
- If the GitHub Pages URL initially shows 404, wait a few minutes and re-check the Pages settings.
